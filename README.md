# Stellar.PhotoStudio

StellarResonance plugin for screenshots — photo-mode tooling (UI hiding, high-resolution capture, look presets) with optional ReShade integration. Design in progress.

Builds against the published SDK (no framework checkout or game install):

```bash
dotnet build -c Release
```

Published via the [plugin registry](https://github.com/StellarProtocol/StellarResonancePlugins) (manifest pins this repo + commit; CI builds it in an isolated container). AGPL-3.0-or-later.
